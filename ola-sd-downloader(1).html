OLA SD card downloader

Pull log files off an OpenLog Artemis over USB, without removing the card. Close CoolTerm and the Arduino Serial Monitor first, since only one program can use the port.

Run this page in Google Chrome on a desktop or laptop computer. Other browsers can’t connect to the OLA over USB.

This browser can’t talk to USB serial devices. Open this file in Chrome or Edge on a desktop computer.
Not connected
  1. Connect to the OLA

    Pick the OLA’s port in the browser’s popup.

  2. Open the file menu

    Pauses logging and lists the files on the card.

  3. Download files

    Use the Download buttons on the file list.

  4. Resume logging

    Leaves the menus so the OLA starts logging again.

Files on the card

  • Connect and open the menu to see files.
